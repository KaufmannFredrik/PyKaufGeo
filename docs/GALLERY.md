# PyKaufGeo gallery

What each finished milestone looks like, newest first. Generated by `python tools/gallery.py`
from PLAN.md, the milestone demos (`pykaufgeo/demos.py`) and the design review screenshots.

Open a demo yourself:

```
python -m pykaufgeo --demo        # the newest milestone
python -m pykaufgeo --demo m2     # a given milestone
dist/PyKaufGeo.exe --demo         # the built program (python build.py)
```

or use Help > Milestone Demos in the app. Demos open unsaved; nothing is overwritten.

## M3: Full tool set, transformations, conics, polygons, locus, sliders, animation, styling, properties

**Try it:** `python -m pykaufgeo --demo m3`. Drag M along its circle (Q draws the magenta locus), P along the ellipse (the tangent follows) or A (the triangle and its mirror image change). Press PLAY in the view bar or drag the slider r. Right-click an object for its menu, Ctrl+E for Properties, and try the tools.

## M2: 2D graphics view, input bar, algebra view

**Try it:** `python -m pykaufgeo --demo m2`. Drag A or B. Scroll to zoom at the cursor, right-drag a rectangle to zoom into it, change the grid in the view bar. tan(x) and floor(x) - 5 break cleanly at poles and jumps. Type Cir in the input bar to see autocomplete; F1 opens the command help.
